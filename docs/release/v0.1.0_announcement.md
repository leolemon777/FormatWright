## 中文长文（论坛/博客/RSS）

**Anole v0.1.0 公测发布：一个"能验证结果"的本地文件转换器**

Anole 是一个开源（Apache-2.0）、本地优先、零遥测的文件转换器。它和大多数转换工具的区别只有一个词：验证。每次转换都会先给出可解释的 Plan（为什么走这条路、有损还是无损），执行后逐项验收并留下机器可读的收据——文件类型、页数、轨道、哈希守恒——而不是拿退出码 0 当成功。

- 172 条可达转换组合（103 条直连 + 69 条链式，canonical 口径，计数脚本随仓库发布），每一段链路都有独立验收
- PDF 工具箱（旋转/压缩/加密/水印/合并/元数据）、zip↔tar.gz↔7z 档案互通、EML 邮件（自动剥脚本与远程资源）、OCR、HTML/SVG→矢量 PDF
- 持久化任务队列：断电/崩溃后可恢复，批量任务可暂停续跑
- CLI、桌面 GUI、REST API 三种形态，同一个 Rust 内核
- 许可证洁癖：不捆绑任何第三方引擎，在本机发现并校验引擎，附 SPDX SBOM

下载：GitHub Releases（`SHA256SUMS` 可校验）。当前安装包未购买代码签名证书，SmartScreen 会提示，选"仍要运行"即可；签名版 v0.1.1 跟进。

## English long-form (forum/blog)

**Anole v0.1.0 Public Beta: a local file converter you can verify**

Anole is an open-source (Apache-2.0), local-first, zero-telemetry file converter. One word separates it from most converters: verification. Every job starts with an explainable plan (why this route, lossy or lossless), and ends with per-check acceptance evidence — file types, page counts, tracks, hash conservation — in machine-readable reports. An exit code of zero is not our definition of success.

- 172 reachable conversion routes (103 direct + 69 chained, canonical counting; the counter ships in the repo), every hop validated
- PDF toolbox (rotate/compress/encrypt/watermark/merge/metadata), zip↔tar.gz↔7z interconversion, EML email with script/remote-resource sanitization, OCR, HTML/SVG→vector PDF
- Durable job queue: crash-recoverable, pausable batches
- CLI, desktop GUI, and REST API over one Rust core
- License hygiene: no bundled third-party engines — discovered and verified on your host, SPDX SBOM attached

Download from GitHub Releases (verify with `SHA256SUMS`). The installer is currently unsigned (SmartScreen will warn — "More info" → "Run anyway"); a signed v0.1.1 will follow.

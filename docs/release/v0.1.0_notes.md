# Anole v0.1.0 (Public Beta, Unsigned Alpha)

**Anole** 是一个本地优先、零遥测的文件转换器：每一次转换都经过规划、执行和验证，并留下机器可读的验收收据。以 Apache-2.0 开源，提供 CLI、桌面 GUI 与 REST API 三种形态。

**Anole** is a local-first, zero-telemetry file converter: every conversion is planned, executed, and validated, with machine-readable acceptance evidence. Open source under Apache-2.0, shipping as a CLI, a desktop GUI, and a REST API.

## Highlights

- **319 reachable conversion routes** (228 direct + 91 chained through whitelisted one-hop intermediates), each hop carrying its own validation evidence.
- **PDF toolbox**: rotate, compress, encrypt/decrypt, watermark, metadata, merge/extract, page-to-image.
- **Archives**: zip ↔ tar.gz ↔ 7z interconversion with manifest conservation.
- **Email**: EML family with script and remote-resource sanitization (email is untrusted input).
- **OCR**: PDF → searchable PDF via Tesseract.
- **Browser print lane**: HTML/SVG → vector PDF through a discovered Chromium-family browser.
- **Engineering**: durable SQLite job queue with crash recovery, plan-first approval (`plan_hash` binding), sandboxed untrusted inputs, tri-platform CI, 10k-job soak evidence.
- **License hygiene**: engines are discovered on your host and never bundled — the doctor never downloads anything.

## Install (Windows x64)

1. Download `Anole_0.1.0_x64-setup.exe`.
2. Verify against the attached `SHA256SUMS`.
3. Run the installer. First start activates the pinned starter engine packs and offers a doctor check.

> **Unsigned Alpha notice**: this installer carries no Authenticode signature yet, so Windows SmartScreen will show a warning — choose "More info" → "Run anyway". A signed v0.1.1 will follow once the code-signing certificate is in place.

Linux: see the repository README for the engine guide; packages for Linux are planned for a later release.

## Updates

The in-app "Check for updates" action verifies minisign signatures against the pinned public key; `latest.json` ships with this release.

## Supply chain

`SHA256SUMS` and the SPDX 2.3 application SBOM (`Anole-0.1.0-sbom.spdx.json`) are attached. Engine-pack SBOM sidecars ride inside the installer.

本地 API 演示 · Local REST API demo

先把服务跑起来，再用这张页面调 API。

这是一个纯静态演示页（零依赖、零构建），直接调用本机 FormatWright REST API： POST /v1/plan 做转换预案预览，POST /v1/convert 执行转换并渲染返回的验收回执（ValidationReport）。

前置条件：本页面不联网、不上传文件，API 必须由你自己在本机启动。在仓库根目录运行： cargo run -p formatwright-server --release 服务默认监听 http://127.0.0.1:8787（可用 --bind 127.0.0.1:8788 换端口，本页固定按 8787 探测）。 下方的格式互转走内置结构化引擎，无需安装 ffmpeg 等外部引擎。
